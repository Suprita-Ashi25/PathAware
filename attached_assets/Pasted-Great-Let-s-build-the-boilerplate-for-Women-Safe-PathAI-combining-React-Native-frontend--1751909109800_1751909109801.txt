## 1️⃣ `client/` – React Native App (Expo)

### ✅ Setup

```bash
npx create-expo-app client -t expo-template-blank
cd client
npm install expo-location expo-sensors expo-av react-native-gesture-handler
npm install @react-native-async-storage/async-storage
```

### ✅ Sample `App.js`

```js
import React, { useEffect } from 'react';
import { View, Text, Alert } from 'react-native';
import * as Location from 'expo-location';
import { Accelerometer } from 'expo-sensors';

export default function App() {
  useEffect(() => {
    (async () => {
      const { status } = await Location.requestForegroundPermissionsAsync();
      if (status !== 'granted') {
        Alert.alert("Permission denied");
        return;
      }

      const location = await Location.getCurrentPositionAsync({});
      console.log('📍 Location:', location);
    })();

    const subscription = Accelerometer.addListener(accel => {
      const speed = Math.sqrt(accel.x ** 2 + accel.y ** 2 + accel.z ** 2);
      if (speed > 2.5) {
        console.log("🚨 Panic Movement Detected");
        // TODO: Trigger SOS
      }
    });

    return () => subscription.remove();
  }, []);

  return (
    <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
      <Text>🛡️ Women Safe PathAI is running</Text>
    </View>
  );
}
```

## 2️⃣ `server/` – Node.js Express Backend

### ✅ Setup

```bash
mkdir server && cd server
npm init -y
npm install express cors dotenv
```

### ✅ `index.js`

```js
const express = require('express');
const cors = require('cors');
require('dotenv').config();

const app = express();
app.use(cors());
app.use(express.json());

app.get('/ping', (req, res) => {
  res.send("🔗 Backend is alive");
});

app.listen(4000, () => {
  console.log('✅ Server running on http://localhost:4000');
});
```

## 4️⃣ `firebase/` – Firebase Setup

### ✅ Features

* Auth (email/OTP or anonymous)
* Realtime DB (for live SOS / location tracking)
* FCM (notifications)

Use Firebase Console:

* Create project
* Enable Auth + Firestore + Cloud Messaging
* Download `google-services.json` for Android or `.plist` for iOS

Then connect to `client/` using `firebase` SDK.
